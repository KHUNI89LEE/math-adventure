# 수와 연산 탐험대 v2 — 수학 시각화 강화판

## 포함 기능
- 덧셈, 뺄셈, 곱셈, 나눗셈, 수 감각 문제
- 수직선·배열·묶음 시각화
- 단계별 힌트와 여러 계산 방법
- 경험치·레벨·연속 정답
- 부모용 영역별 정답률 및 추천 학습
- 인터넷이 끊겨도 실행되는 오프라인 캐시

## 가장 쉬운 실행 방법: GitHub Pages
1. GitHub 계정을 만들고 새 저장소를 생성합니다.
2. 이 폴더 안의 파일을 모두 저장소 최상위에 업로드합니다.
3. 저장소의 Settings → Pages로 이동합니다.
4. Build and deployment에서 `Deploy from a branch`를 선택합니다.
5. Branch를 `main`, 폴더를 `/root`로 선택하고 Save를 누릅니다.
6. 생성된 주소를 갤럭시 탭 Chrome에서 엽니다.
7. Chrome 오른쪽 위 ⋮ → `홈 화면에 추가` 또는 `앱 설치`를 누릅니다.

## PC에서 먼저 테스트
PWA 기능은 file:// 방식으로는 정상 동작하지 않으므로 간단한 웹서버가 필요합니다.

Python이 설치된 PC:
```bash
cd math_adventure_pwa
python -m http.server 8000
```
그 뒤 Chrome에서 `http://localhost:8000`을 엽니다.

## 같은 와이파이에서 갤럭시 탭으로 시험하기
1. PC에서 위 서버를 실행합니다.
2. 명령 프롬프트에서 `ipconfig`를 실행해 PC의 IPv4 주소를 확인합니다.
3. 갤럭시 탭 Chrome에서 `http://PC주소:8000`으로 접속합니다.
4. Windows 방화벽이 물으면 Python의 개인 네트워크 접근을 허용합니다.

주의: 정식 PWA 설치는 HTTPS 주소(GitHub Pages 등)에서 가장 안정적입니다.

## 파일 설명
- index.html: 화면 구조
- style.css: 태블릿 반응형 디자인
- app.js: 문제 생성, 시각화, 기록 저장
- manifest.json: 앱 설치 정보
- sw.js: 오프라인 실행
- icons/: 앱 아이콘

## 기존 GitHub 앱 업데이트
1. 이 ZIP의 압축을 풉니다.
2. GitHub 저장소에서 `Add file → Upload files`를 누릅니다.
3. 압축을 푼 폴더 안의 파일과 icons 폴더를 모두 끌어다 놓습니다.
4. 같은 이름의 기존 파일은 새 버전으로 교체됩니다.
5. 아래 `Commit changes`를 누릅니다.
6. 1~3분 후 기존 앱 주소를 새로고침합니다.
