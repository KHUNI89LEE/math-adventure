# 콩콩 수학 놀이터 V6

만 4세이지만 사칙연산 기초가 있는 아이를 위한, 그림·애니메이션 중심 수학 놀이터입니다.

## 포함된 놀이
- 기차역: 더하기·빼기
- 피자 가게: 나누기·분수의 기초
- 동물 농장: 곱하기·배열
- 무지개 정원: 규칙·추론
- 블록 연구소: 공간·비교·차이
- 동전 마트: 돈·뺄셈

## GitHub Pages 올리는 방법
1. ZIP 파일의 압축을 풉니다.
2. `index.html`, `style.css`, `app.js`, `manifest.webmanifest`, `sw.js`, `icons` 폴더를 저장소 최상단에 업로드합니다.
3. GitHub 저장소의 **Settings → Pages**에서 `Deploy from a branch`를 선택합니다.
4. Branch는 `main`, Folder는 `/ (root)`를 선택하고 저장합니다.
5. 기존 페이지가 캐시되어 있으면 주소 뒤에 `?v=5`를 붙여 한 번 열어 주세요.

## 특징
- 별도 빌드 과정 없음
- React/Node.js 설치 불필요
- 갤럭시탭 홈 화면 설치 가능
- 오프라인 캐시 지원
- 별과 스티커 진행 상황은 기기에 저장
