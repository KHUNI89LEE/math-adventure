# 서준이의 수학 마을 V13

GitHub Pages용 PWA입니다.

## V13 변경 사항
- 피자 가게: 한 자리, 두 자리, 세 자리 수 ÷ 한 자리 수 문제
- 큰 수 나눗셈: 피자 10조각 묶음과 낱조각으로 분배 시각화
- 동물 농장: n개씩 동그라미로 묶고 묶음 수를 순차 표시
- 동전 마트: 50,000원부터 1원까지 실제 한국 원화 단위 표시
- 같아요 연구소 숨은 상자: `4 = 3 + □`, `6 = 2 × □` 형태의 숫자 등식
- 퍼즐하우스 기억 놀이: 여섯 장, 세 쌍을 모두 맞혀야 다음 문제로 이동
- 메인 이름: 서준이의 수학 마을

ZIP 내부 파일 전체를 GitHub 저장소 최상위에 덮어 올려 사용하세요.
