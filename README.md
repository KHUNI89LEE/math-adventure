# 콩콩 수학놀이터 V12

GitHub Pages에 바로 업로드할 수 있는 PWA 버전입니다.

## V12 추가 내용
- 무지개 정원: 반복, 개수, 방향, 모양, 색+모양, 위치, 성장, 시간 규칙
- 퍼즐하우스: 다른 그림, 그림자, 빠진 조각, 같은 그림 기억
- 탐정사무소: 단서를 순서대로 확인하는 이야기형 추리
- 블록 공방: 회전, 좌우 대칭, 대칭 완성
- 집중력 놀이터: 개수 세기, 3초 순서 기억, 숨은 그림 찾기
- 레벨 및 잠금 해제 없음: 모든 건물은 처음부터 자유롭게 이용

## 설치
저장소의 기존 파일을 모두 이 폴더의 파일로 덮어쓴 뒤 GitHub Pages에서 확인하세요.
캐시가 남으면 주소 뒤에 `?v=12.0`을 붙여 확인하세요.
